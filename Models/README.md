# Models and Artifacts

This folder is for trained model artifacts and preprocessing components.


- final_kmeans.joblib: Trained K-Means clustering model
- scaler.joblib: Feature scaler
- variance_threshold.joblib: Feature selector
- pca.joblib: PCA transformer
- config.json: Run metadata

If artifacts are not included due to size, they can be regenerated by running the notebook end-to-end.
